## 2. 采集方式

- 使用 Python `requests` 直接请求公开 HTML，`BeautifulSoup` 解析；不使用浏览器自动化采集。
- 仅请求列表页和详情页，不请求登录态接口、不提交表单、不下载附件。
- 每个请求间隔默认 **0.8 秒**；同一 URL 最多 **3 次**尝试；串行请求，无并发。
- 通过 `User-Agent` 标明普通浏览器；不伪造登录态、不绕过验证码/Cookie/WAF。
- 本地 HTML 缓存仅用于断点续跑和减少重复请求，缓存目录 `data/cache/` 不进入 Git。

## 3. 合规边界

1. **只抓公开页面**：所有数据均来自无需登录即可访问的页面。
2. **不绕过访问控制**：`content.jsp?...` 的 5 条通知返回「请登录客户端 VPN 后浏览」（HTTP 403），爬虫未尝试登录 VPN、未伪造内网请求，仅保留标题与公开链接，正文为空。
3. **不抓个人敏感信息**：教师信息只保留官网主动公开的姓名、院系、职称、导师类别、研究方向、毕业院校、公开邮箱和公开简介；不采集手机号、住址、身份证号、家庭信息等。
4. **保留出处**：每条数据保留 `source_url`，Excel 链接列可直接跳转原文。
5. **最小化引用**：Excel 的「正文」用于站内检索与摘要生成；对外展示时应以标题、摘要和原文链接为主，不整篇转载。
6. **用途限制**：仅用于校园综合互助平台课程项目的信息库演示，不用于商业用途、批量转载或对抗第三方反滥用系统。
7. **可删除**：如来源方要求下架，删除 `source_url` 对应记录并重新生成 seed 即可。
8. **自动脱敏**：爬虫在清洗阶段会把正文中的手机号、座机、身份证号替换为「[已脱敏]」；仓库内 CSV 已按此规则处理。

## 4. robots.txt 检查

两个站点的 `robots.txt` 均返回自定义 404 页面，未提供可解析的抓取规则。基于谨慎原则，仍按上述限速、串行、公开页面范围执行；如后续站点发布 robots 规则，以站点规则为准。

## 6. 字段与映射

团队契约 `data/seed/school-info.csv`：

```csv
id,title,category,summary,source_url
```

`category` 映射到 `InfoCategory` 枚举：

- 通知公告 / 学术通知 → `教务`
- 标题命中招聘、就业、双选、实习 → `就业`
- 标题命中奖学金、助学金、资助 → `奖助`
- 标题命中图书馆、体育馆、场馆 → `场馆`
- 标题命中食堂、宿舍、后勤、校医院 → `生活`
- 其他新闻 → `其他`

`id` 使用 `cumt-news-<URL sha1 前 10 位>`，重复运行保持稳定。完整字段见 `school-info.full.csv` 与 `teacher-info.csv`。

## 7. 复现与维护

```powershell
python -m pip install -r crawler/requirements.txt
python crawler/main.py --max-pages 5 --delay 0.8
```

脚本会重新生成 Excel、CSV、统计和原始 JSON；本地缓存命中时不重复请求。站点改版后只需调整 `cumt_crawler.py` 中的列表/详情选择器。
